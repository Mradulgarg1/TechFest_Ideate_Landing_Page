TECHFEST 2026 — IDEATE LANDING PAGE CONCEPT
===========================================
Files: index.html, style.css, script.js

Preview:
Open index.html in a modern browser.

Publish with GitHub Pages:
1. Upload all four project files to the root of your GitHub repository.
2. Open Settings > Pages.
3. Select Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for the published URL.

Design:
Original landing-page concept inspired by Techfest, IIT Bombay's public themes
of science, technology, competitions and workshops. It uses CSS-made graphics,
responsive layouts and small UI animations. No 3D assets are used.
This is a student concept and is not the official Techfest website or affiliated
with IIT Bombay. Official site: https://techfest.org/

The official site promotes Techfest 2026 for 16–18 December 2026. Prize-pool
and workshop-domain figures are labelled as edition highlights; verify details
on the official website before publishing.
